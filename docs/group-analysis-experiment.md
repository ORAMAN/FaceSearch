# Эксперимент: анализ связей группы лиц

Ветка: `experiment/group-face-analysis`

## Что добавлено

- Кнопка **«Анализ связей группы»** в веб-интерфейсе `server_http.py`. Она доступна после обнаружения двух и более лиц.
- Фоновая задача с прогрессом, чтобы поиск нескольких лиц и проверка социальных связей не блокировали HTTP-запрос.
- Поиск кандидатов для каждого лица с порогом сходства.
- Дедупликация кандидатов: несколько изображений одного профиля не считаются разными людьми.
- Попарная оценка кандидатов по доступным друзьям VK, общим друзьям и совпадению города.
- Ограниченный поиск комбинаций, который не назначает один и тот же профиль двум разным лицам. Если для лица не удалось подобрать уникальный профиль, оно может остаться несопоставленным.
- Граф для выбранной комбинации и список альтернативных комбинаций.
- Постоянные параметры в окне desktop-приложения и временные параметры в браузере.

## Настройки

Постоянные значения открываются в главном окне FaceSearch кнопкой **«Параметры группового анализа»**. Они сохраняются в существующий `settings.xml` и используются сервером при запуске.

Поля, изменённые на странице браузера, применяются только к запущенному анализу и не сохраняются в `settings.xml`.

Параметры:

- минимальное сходство кандидата, %;
- число кандидатов на каждое лицо (1–10);
- вес прямой дружеской связи;
- вес общих друзей;
- вес совпадения города;
- включение/отключение проверки друзей VK.

## VK и ограничения

Проверка друзей включается по умолчанию, но выполняется только если найден токен VK в одном из стандартных файлов:

`loaders/vk/vk_token.txt`, который ведёт загрузчик VK.

Получение, проверка и сохранение токенов остаются в загрузчике VK: «Получить токен через VK ID…» или «Добавить токен v1 вручную…». Анализ подключается к модулю `loaders/vk/vk_downloader.py`, перечитывает его пул токенов при изменении файла и использует штатную ротацию токенов и повторные запросы API. Отдельного ввода или формата токенов в браузере нет. Если рабочие токены отсутствуют, доступ к друзьям закрыт или API возвращает ошибку, анализ продолжится по доступным признакам; интерфейс сообщит о неполных данных. Загружаются только ID друзей, не их профили и фотографии. Для нагрузки введены кеш, ограничение числа кандидатов и ограничение скорости запросов.

## Как интерпретировать результат

Общий рейтинг — эвристический показатель согласованности набора кандидатов, а не статистическая вероятность правильного определения людей. Отсутствие данных о дружбе не считается доказательством отсутствия связи. Совпадение города — слабый признак, не самостоятельное подтверждение.

## Проверка

Базовые модульные тесты находятся в `tests/test_group_analysis.py` и запускаются из корня репозитория:

```powershell
python -m unittest discover -s tests -p "test_group_analysis.py" -v
```

Эта экспериментальная ветка не изменяет `main` и не требует изменения схемы основной базы данных.
