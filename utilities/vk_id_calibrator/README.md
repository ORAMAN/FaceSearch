# VK ID Calibrator

Приложение для получения дат регистрации пользователей VK по ID, построения опорных точек и приблизительных диапазонов ID по годам.

## Возможности

- Поиск верхней доступной опорной точки в заданном диапазоне ID.
- Получение дат регистрации для набора опорных ID.
- Расчёт приблизительных границ диапазонов ID по годам.
- Проверка даты регистрации одного ID без запуска полной калибровки.
- Кэширование ранее полученных дат.
- Сохранение результатов после каждой опорной точки и автоматическое продолжение прерванной калибровки с того же места.
- Экспорт опорных точек и годовых диапазонов в CSV.

## Требования

- Windows 10 или Windows 11.
- Python 3.10 или новее, добавленный в `PATH`.
- Доступ к Интернету.
- Google Chrome или Chromium, установленный через Playwright.

Для CAPTCHA приложение использует отдельное окно Chrome/Chromium. Если Google Chrome установлен не в стандартной папке, его расположение можно указать в настройках приложения. Также можно очистить поле пути к браузеру — тогда будет использоваться Chromium от Playwright.

## Установка и запуск

1. Скачайте ZIP-архив из раздела **Releases** и распакуйте его в отдельную папку.
2. Убедитесь, что Python 3.10+ установлен и доступен из командной строки.
3. Запустите `start_vk_id_calibrator.bat`.
4. При первом запуске BAT-файл установит Playwright и необходимый браузер Chromium.

Для последующих запусков используйте тот же BAT-файл.

## Использование

### Полная калибровка

1. Укажите максимальный ID для поиска.
2. Задайте количество опорных точек.
3. Укажите паузу между запросами и количество повторов при ошибках.
4. При необходимости включите расчёт диапазонов по годам.
5. Нажмите **«Начать калибровку»**.

Результаты появятся на вкладках **«Опорные ID и годы»** и **«Диапазоны по годам»**. Таблицы автоматически прокручиваются к последним добавленным записям.

### Проверка одного ID

Введите числовой VK ID в поле **«Получить дату регистрации одного ID»** и нажмите **«Получить дату»** или клавишу Enter.

По умолчанию приложение использует кэш, если дата уже сохранена. Чтобы выполнить новый запрос к VK, снимите флажок **«Использовать кэш (если есть)»**. Результаты и история проверок отображаются на вкладке **«Одиночные ID»**.

### CAPTCHA

При запросе дополнительной проверки приложение откроет отдельное окно браузера. Пройдите SmartCaptcha вручную. После успешной проверки браузер закроется автоматически, а приложение продолжит запрос.

Программа не распознаёт CAPTCHA автоматически и не использует сторонние сервисы её решения. Не закрывайте окно проверки до завершения CAPTCHA. Операцию можно отменить кнопкой **«Остановить»**.

## Результаты и локальные данные

Приложение хранит рабочие данные рядом с исполняемыми файлами:

| Файл или папка | Назначение |
| --- | --- |
| `vk_dates_cache.json` | Кэш дат регистрации |
| `vk_calibration_results.json` | Накопленные результаты калибровок: опорные точки и варианты диапазонов из разных запусков |
| `vk_single_id_history.json` | История одиночных проверок (до 2000 записей) |
| `vk_id_calibrator_settings.xml` | Настройки приложения в общем XML-формате FaceSearch (параметры формы и состояние окна) |
| `vk_restore_session.json` | Данные сессии VK для работы приложения |
| `browser_profile/` | Профиль браузера, включая cookies и состояние авторизации |

Опорные ID и диапазоны можно экспортировать в CSV с помощью кнопок в главном окне. Новые калибровки дополняют сохранённые результаты: предыдущие опорные точки и варианты диапазонов не удаляются. При первом запуске новая версия автоматически перенесёт настройки из `vk_calibrator_settings.json` в XML. При обновлении приложения не удаляйте файлы локальных данных и папку `browser_profile`, если хотите сохранить результаты, настройки и авторизацию.

## Ограничения

Приложение использует недокументированные методы VK `restore.getSettings` и `restore.init`. VK может изменить их работу, ограничить частоту запросов или потребовать дополнительную проверку.

Годовые диапазоны являются оценкой, а не официальной статистикой VK. Расчёт предполагает, что дата регистрации в целом возрастает вместе с ID. При нарушении этой зависимости приложение не строит диапазоны. Недоступные или удалённые профили также могут влиять на точность результата.

## Конфиденциальность

Запросы отправляются к VK. Профиль браузера может содержать cookies и данные авторизации, поэтому не публикуйте и не передавайте папку `browser_profile` третьим лицам. Не добавляйте локальные файлы сессии и кэша в публичные репозитории.
