VK Downloader для FaceSearch

1. Распакуйте содержимое архива в каталог FaceSearch\loaders\vk.
2. При первом запуске выполните setup.bat из этой папки. Скрипт использует uv и общее окружение .venv в корне FaceSearch.
3. Запускайте start_vk.bat.
4. Чтобы добавить токен: нажмите «Открыть VK ID и добавить токен…», завершите авторизацию в браузере, скопируйте URL перенаправления с #access_token= или сам токен и вставьте его в диалог. Приложение проверит токен через VK API и только после успешной проверки запишет его в vk_token.txt.
5. Если старая ссылка авторизации перестала работать, получите токен способом, который доступен вашей VK ID app, и вставьте значение/redirect URL вручную.

Возможности: глубина обхода друзей (0 и выше), обработка групп без обхода друзей, настройка числа потоков загрузки фотографий, JSON рядом с изображениями, опциональный импорт в FaceSearch, создание CROP, построение FAISS после импорта и удаление исходных файлов после успешного импорта.

Токены хранятся в открытом виде в vk_token.txt. Не публикуйте этот файл и отзывайте токены, которые могли попасть в исходный код или логи.
