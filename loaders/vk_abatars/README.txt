Загрузчик аватарок VK для FaceSearch

Установка и запуск
1. Папка загрузчика: FaceSearch\loaders\vk_abatars.
2. При первом запуске выполните setup.bat. Он устанавливает зависимости в общее окружение .venv в корне FaceSearch.
3. Запускайте start_vk_abatars.bat.

Возможности
- Загружает только аватарки пользователей и групп VK, без альбомов и остальных фотографий.
- Для пользователей поддерживает обход друзей по уровням глубины.
- Сохраняет Avatar.jpg и Avatar.json со штатной структурой метаданных FaceSearch.
- Может импортировать аватарки в активный профиль FaceSearch, создавать CROP, строить FAISS-индекс после импорта и удалять исходную пару после успешного импорта.
- Проверяет profiles.profile_url именно в активной базе FaceSearch. Если уже найден URL вида https://vk.com/id123 или https://vk.ru/id123, соответствующий ID пропускается. Проверка работает и при отключённом импорте.
- Использует те же файлы токенов VK и постоянный профиль Chrome, что и загрузчик в loaders\vk. Настройки и каталог скачивания хранятся отдельно.

Авторизация
Токены не дублируются: используются loaders\vk\vk_token.txt, vk_service_token.txt и vk_silent_token.json. Не публикуйте файлы токенов и отзывайте токены, которые могли стать доступны посторонним.

База FaceSearch
При включённом импорте аватарки добавляются штатным импортёром FaceSearch. При выключенном импорте загрузчик подключается к активной БД только для проверки существующих profile_url и не меняет схему таблицы images.
